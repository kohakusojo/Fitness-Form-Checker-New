# 筋トレフォームチェック（新規構築版）

元プロジェクト: https://github.com/NgoQuocBao1010/Exercise-Correction （MIT License）

## 概要
MediaPipe Pose Landmarkerを使うStreamlit試作版。ベンチプレス・アームカール・スクワットに対応。
骨格描画、角度推移、簡易回数カウント、CSV・動画出力を実装しています。

**重要:** 元プロジェクトの学習済み分類モデルは本ZIPには含まれていません。モデル推論や正誤分類は未実装です。モデルの特徴量抽出・ラベル・前処理を確認して別途統合する必要があります。ベンチプレスのモデルは新規学習が必要です。

## 公開方法
1. ZIPを解凍し、ファイルを新しいGitHubリポジトリのルートにアップロード。
2. Streamlit Community Cloudで `streamlit_app.py` を指定。
3. Python 3.12を選択してデプロイ（runtime.txtも同梱）。
4. 初回の姿勢モデルファイルはGoogle Storageからダウンロードします。通信が遮断されている環境では手動で同じ `.task` ファイルを配置してください。

## 注意
角度と回数は撮影方向や遮蔽に影響されます。安全性や医学的適切性の判定ではありません。出力MP4はブラウザで再生できない場合があり、その際はローカルプレイヤーで確認してください。
